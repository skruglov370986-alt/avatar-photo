AVATAR PHOTO v0.1 — статический веб-проект.
1. Распакуйте архив. index.html и decor.png должны находиться в одной папке.
2. Разместите оба файла на HTTPS-хостинге. Например, GitHub Pages: создайте репозиторий, загрузите файлы в корень, Settings → Pages → Deploy from a branch → main / root. Откройте выданную ссылку на iPhone в Safari.
3. Нажмите «Включить камеру», разрешите доступ. Для проверки без камеры загрузите JPG комнаты.
4. Снимайте угол комнаты примерно с 2,5–3 м, отрегулируйте масштаб и положение декора пальцем. Выберите таймер и нажмите «Снять фото».
5. Сохраните JPG через «Поделиться» или «Скачать JPG».
Обработка локальная, без отправки фото. Нет трекинга пространства и сегментации людей; декор рисуется поверх кадра. При перекрытии человека измените его позицию или положение декора. Графика статична, снег анимирован. На горизонтальном кадре используется тот же вертикальный ассет. Реальная камера iPhone не проверена в среде разработки.
