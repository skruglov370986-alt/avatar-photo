AVATAR PHOTO v0.2 — экспериментальная сборка

Обновление GitHub Pages:
1. Распаковать ZIP. В репозитории avatar-photo выбрать Add file → Upload files.
2. Загрузить все файлы из архива в корень main, подтвердить Commit changes.
3. Дождаться успешного pages build and deployment во вкладке Actions.
4. Открыть https://skruglov370986-alt.github.io/avatar-photo/?v=02 в Safari.

Использование:
- Включить камеру, включить «Люди перед декором». Модель MediaPipe загружается с jsDelivr, обработка кадра локальная. Дождаться сообщения об активном выделении.
- Если модель не загрузилась, обычный режим остаётся доступным.
- «Настройка декора»: выбрать объект, перемещать пальцем, менять масштаб. Сброс возвращает всю сцену.
- «Тени» включает условную овальную тень. Для широкого кадра боковые слои раздвигаются.
- Снять фото, нажать «Сохранить в Фото / Поделиться» и выбрать «Сохранить изображение», если iOS предлагает этот пункт. Альтернатива — Скачать JPG в Файлы.
- Загрузка тестового фото находится в дополнительных настройках.

Ограничения: графические слои вырезаны из одной иллюстрации, а не являются отдельными чистыми рендерами. При сильном перемещении возможны видимые стыки и пустоты. Нет AR-трекинга, физических теней и нового горизонтального рендера. Сегментация экспериментальная, качество зависит от освещения, расстояния и числа людей. Для модели нужен интернет; камера и сегментация на iPhone в этой версии не проверены. Синтаксис JS проверен Node.js.
